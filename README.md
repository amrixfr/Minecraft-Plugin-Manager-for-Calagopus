# Minecraft Plugin Manager for Calagopus

A plugin manager extension for Calagopus Panel that lets you browse, search, download, and install Minecraft plugins directly from your server panel.

[Calagopus Panel](https://calagopus.com)
[Latest Release](#installation)
[License: MIT](LICENSE)

## Features

* **Plugin Browser:** Browse Minecraft plugins directly from your panel without visiting external websites.
* **Modrinth Integration:** Search and browse Minecraft plugins available on Modrinth.
* **Plugin Search:** Find plugins by name, keyword, or category.
* **One-Click Installation:** Download and install plugins directly into your Minecraft server's `plugins` folder.
* **Version Selection:** Choose compatible plugin versions for your Minecraft server.
* **Game Version Filter:** Filter plugins by Minecraft version.
* **Platform Support:** Find plugins for Paper, Spigot, and other supported Minecraft server platforms.
* **Plugin Information:** View plugin descriptions, authors, supported versions, and download information.
* **Plugin Management:** View installed plugins and manage them directly from the panel.
* **Simple Interface:** A clean and modern interface designed to work seamlessly with Calagopus.
* **Easy Updates:** Check for newer plugin versions and update installed plugins.
* **Responsive Design:** Use the plugin manager on desktop, tablet, and mobile devices.

## Installation

1. Download the latest `.c7s.zip` extension from the [Releases](../../releases) page.
2. Open your Calagopus Panel.
3. Navigate to **Admin → Extensions**.
4. Upload and install the extension.
5. Restart the panel if required.

After installation, open the Minecraft Plugin Manager from your server panel.

## Usage

1. Open your Minecraft server in Calagopus.
2. Navigate to the **Plugin Manager**.
3. Search for the plugin you want to install.
4. Select the plugin and choose a compatible version.
5. Click **Install** to download it to your server.
6. Restart your Minecraft server if necessary.

## Requirements

* Calagopus Panel
* A Minecraft server
* An internet connection to download plugins
* A supported Minecraft server platform
